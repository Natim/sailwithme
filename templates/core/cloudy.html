{% trans "Cloudy, the online pilot logbook" %}

{% blocktrans trimmed %} Sail with Me and Cloudy are both published by SAS CLOUDY. Cloudy, on cloudy.fr, keeps an electronic copy of a pilot logbook: the line for the day, the totals, and a logbook you can open again when you need it. {% endblocktrans %}

{% trans "After the flight" %}

{% blocktrans trimmed %} Back on the ground, you open the logbook on cloudy.fr and enter the flight as on paper: date, aircraft, flight time, and function on board. The totals update from the lines you enter. {% endblocktrans %}

{% trans "The same account covers several activities. Cloudy has a logbook for each:" %}

  • {% trans "aeroplane, in DGAC or FCL 1.080 format" %}
  • {% trans "glider" %}
  • {% trans "helicopter" %}
  • {% trans "microlight, in FFPLUM format" %}
  • {% trans "balloon" %}
  • {% trans "parachute" %}

{% trans "What you get" %}

  • {% trans "Hour totals calculated from the flights you enter." %}
  • {% trans "A PDF export in the DGAC or FCL 1.080 layout, plus XLS and CSV, and sending the logbook by email." %}
  • {% trans "Cloudy Alerts: an email several weeks before a licence or rating expires, once the profile is filled in." %}
  • {% trans "Statistics drawn from your flights." %}
  • {% trans "Photos, annotated charts, and navigation documents attached to a flight." %}
  • {% trans "Import of a logbook already kept elsewhere, from Excel, CSV, or another file." %}

{% trans "Two plans" %}

{% blocktrans trimmed %} Signing up on cloudy.fr is free. The free plan includes one logbook of your choice, import of an existing logbook, hour totals, and 10 MB of storage. {% endblocktrans %}

{% blocktrans trimmed %} First Class is €2.99 per month, or €35 per year. It opens unlimited logbooks, email reminders, detailed statistics, exports, and unlimited storage. {% endblocktrans %}
